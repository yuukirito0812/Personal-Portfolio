PREVIEW LOCALLY
1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. Click any certificate to see it in the full-size viewer (Arrow Left/Right moves through certificates).
4. Use the poster thumbnails to see all four designs; click View full size to open a poster.

PUBLISH / UPDATE THE EXISTING NETLIFY WEBSITE
1. Sign in to https://app.netlify.com/
2. Select your existing portfolio website, then choose its Deploys section.
3. Manually deploy the extracted folder containing index.html, app.js, style.css, and media/.
4. Refresh your public URL using Ctrl+Shift+R if a cached older version appears.
